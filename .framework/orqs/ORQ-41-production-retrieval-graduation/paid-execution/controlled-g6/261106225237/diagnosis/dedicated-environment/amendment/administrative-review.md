# Independent administrative procedure review

**ADMINISTRATIVE_PROCEDURE_REVIEW_FINDINGS**. The placement intent is understandable, but this draft is not yet a safe executable application/rollback procedure. Two HIGH findings block host application. No host writes, systemctl/Docker/SQL/API/provider operation or source edit was performed by reviewer; counterexamples below are static interruption/command-order walkthroughs, not actual host experiments.

## ADMIN-R1 — HIGH — partial/crash recovery is not executable

administrative-procedure.md:53–68 applies several independent privileged mutations;67–68 only instructs checking return codes and restoring already-applied steps. A successful first two restrictions followed by session loss/SIGKILL does not produce a return-code branch in a surviving orchestrator. There is no persistent intent/applied/readback state, serialized administration ownership or independent recovery trigger. The evidence-directory instruction is not a durable operation journal, recovery protocol or watchdog.

Static reproduction: create/start bench slice, restrict user.slice and machine.slice successfully, then lose the administrator session before system.slice/init.scope. The machine remains partly changed; no automatic restoration or exact restart-from-state procedure is defined. Re-running generic restore commands may overwrite concurrent administrator changes and cannot prove which files/actions belong to this attempt. This matters because the modifying session, Codex/editor and system services are themselves affected by the operation.

Minimal closure: root-controlled durable baseline/ownership manifest, exclusive maintenance ownership, write-ahead intent plus applied readback for every mutation (including ambiguous command outcomes), explicit idempotent partial/crash recovery and a recovery path independent of the modifying session. An administrator-supported watchdog or equivalent independent privileged recovery mechanism must be specified/tested before applying; a shell trap alone cannot handle SIGKILL/session failure. Define safe disarm/extension and no-restore-while-owned-benchmark-work-is-active conditions, refuse unexpected concurrent state, preserve logs. Do not silently reboot, stop source services or invent a previous EPP value.

## ADMIN-R2 — HIGH — ownership/file rollback is deferred and reload order incomplete

administrative-procedure.md:111–123 and128–130 explicitly leave actual runtime property-file ownership/restoration to a later reviewed implementation. The known empty AllowedCPUs/DropInPaths baseline simplifies desired values but does not identify all files created by set-property, including rollback set-property writes. The sequence reloads after deleting the bench unit, then discusses restoring/removing owned property fragments; no final reload after those fragment changes is required. Empty live AllowedCPUs alone does not prove restored disk/manager parity.

Static reproduction: with no original drop-ins, apply creates runtime property fragments. Rollback's set-property AllowedCPUs= may itself leave fragments; the commands do not specify exact owned paths or recording of those writes. If later fragments are removed/restored after the only listed reload, manager DropInPaths/state can remain out of sync with filesystem evidence. Unknown/partially applied files cannot safely be guessed or broadly removed. The draft correctly forbids glob deletion/systemctl revert, but does not supply the necessary executable alternative.

Minimal closure: define the supported discovery/capture method and exact root-owned file allowlist before mutation, ownership/pre/post hashes for apply and restore writes, and refusal of missing/replaced/concurrently edited files. Restore/remove only that attempt's files, then daemon-reload after ALL file changes and verify file bytes/absence, FragmentPath/DropInPaths, AllowedCPUs/StartupAllowedCPUs/effective placement and source-container no-restart identity. Explicitly test slice emptiness before stopping it; a textual instruction not to destroy work is not an enforceable check. Preserve any residual mismatch as cleanup FAILED. This need not alter application/harness/runtime semantics.
